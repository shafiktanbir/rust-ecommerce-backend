# 🤖 Agent Guide: How to Generate High-Converting Technical Posts from Benchmark & SRE Data

This guide instructs AI agents on how to extract engineering metrics from this repository (`rust ecommerse-loop`) and write viral, technical-authority posts for LinkedIn, X (Twitter), Engineering Blogs, and Cold Outreach campaigns targeting Founders and CTOs.

---

## 🎯 Target Persona Definitions

When generating or updating post ideas, always tailor the narrative to one of these two key decision-makers:

### 1. The Bootstrapped / Seed Technical Founder (CEO / Founder)
* **What they care about**: Cloud cost optimization, avoiding massive AWS bills, high system reliability without hiring a large team, getting enterprise scale on budget.
* **Keywords**: "Cloud burn", "$20/month stack", "Zero hardware upgrade", "400M requests/day", "Bootstrapped reliability".

### 2. The CTO / VP of Engineering / SRE Lead
* **What they care about**: Hard performance data, Little's Law, eliminating 504 timeouts, preventing PostgreSQL connection starvation, zero data loss (ACID outbox), fast Docker CI/CD caching.
* **Keywords**: "Little's Law", "p95 tail latency", "sysctl rp_filter", "SKIP LOCKED", "ExclusiveLock serialization", "cargo-chef".

## 📐 The 5-Step Technical Post Creation Formula

Every post generated by an agent MUST follow this 5-step structure:

### Step 1: Viral Hook with Hard Metrics
Start with an unexpected technical paradox or drastic metric shift.
* **Good**: "We fired 3,000 VUs at our €20/mo Rust API... and got 504 Gateway Timeouts despite 15% CPU usage."
* **Bad**: "Here is how to set up Nginx with Rust."

### Step 2: Diagnostic Funnel & Technical Problem
Explain what failed under load using empirical logs, architectural diagrams, or SRE principles (e.g. Asymmetric Routing, Connection Pool Exhaustion, Row Lock Serialization).

### Step 3: Minimal Code / Config Fix
Provide exact, production-ready code diffs or sysctl/YAML configs (e.g., `rp_filter = 2`, `LPUSH` Redis queueing, `FOR UPDATE SKIP LOCKED`).

### Step 4: Empirical Benchmark Verification Table
Always include a clear before/after measurement table with real project data (RPS, p50/p95 latency, error rates, costs).

### Step 5: Cold Outreach Conversion Script
Attach a pre-written, personalized 3-sentence outreach DM that bridges the post topic to a cold outreach opportunity.

2. **Keep Drafts Organized**: All draft post files must be saved in `draft_post_idea/` with standard prefix `0X_topic_name.md`.
